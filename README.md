# 📞 Call Center Visualization – Tableau Case Study

## 📌 Project Overview
This project focuses on analyzing call center data to identify performance patterns across sales representatives. The analysis is designed to support data-driven decision-making through clean, interactive, and user-friendly Power BI dashboards.

---

## 🎯 Business Objective
- Analyze incoming and outgoing call performance
- Identify top-performing sales representatives
- Understand call handling efficiency using talk duration and waiting time
- Deliver insights through visually intuitive dashboards

---

## 📊 Dashboards Created

### 🔹 Dashboard A – Sales Representative & Calls Performance
Includes:
- Total calls per sales rep (Incoming vs Outgoing)
- Top 3 sales reps with highest outgoing calls
- Top 5 sales reps handling the most total calls

---

## 👤 Individual Sales Rep Analysis
- Separate sheets created for each sales representative
- Key KPIs identified:
  - Total Calls
  - Incoming vs Outgoing Calls
  - Average Talk Duration
  - Average Waiting Time
- Charts designed to tell a clear performance story

---

## ⏱ Talk Duration & Waiting Time – Key Insights
- Identified patterns between longer waiting times and increased talk duration
- Certain sales reps handle high call volume with lower waiting times
- Opportunities found for workload balancing and efficiency improvement
